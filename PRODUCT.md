# PRODUCT.md

## Produk
Web absensi piket harian mahasiswa Teknologi Peternakan IPB Angkatan 62.

## Pengguna
- Mahasiswa: mengisi absensi (nama, waktu piket, foto bukti) lewat HP.
- Admin (tunggal): melihat rekapitulasi, filter tanggal, buka foto bukti.

## Tugas utama
1. Mahasiswa submit absensi hanya di jam jadwal (06.00–08.00, 11.00–13.00, 15.00–17.00).
2. Admin rekap harian dengan filter tanggal.

## Bukan tujuan
Landing page marketing, akun multi-user, riwayat untuk mahasiswa.

## Target aksesibilitas
WCAG 2.2 AA dasar: kontras cukup, label form, fokus terlihat, target sentuh >= 44px.
