# DESIGN.md

- Arah: bersih, utilitarian, mobile-first — terinspirasi vibe disekolahku.id (putih + hijau pendidikan, kartu rapi) tapi diadaptasi jadi form & dashboard, bukan landing page.
- Palet: hijau #15803d (aksi utama), hijau gelap #166534 (teks judul), abu #64748b (sekunder), merah #b91c1c (error), latar #f8fafc.
- Tipografi: system-ui stack — cepat, jujur, tidak ada font default tren AI.
- Radius 10–12px konsisten, border tipis #e2e8f0, tanpa shadow berat.
- Tanpa logo, tanpa emoji dekoratif, tanpa gradient/blob.
- Copy konkret: nama field jelas, pesan error spesifik.
- Motion: tidak ada animasi scroll. Hanya ganti state tombol.
- Responsif: form max-width 480px -> 560px di tablet; tabel admin scroll horizontal di HP.
